# 58 Nerazzurri

Gioco di compleanno mobile-first per i 58 anni di mamma, realizzato da Bruno, Alessandro, Christian, Carmen ed Helene.

## Avvio locale

Non richiede compilazione o dipendenze:

```bash
python3 -m http.server 8080
```

Poi aprire `http://localhost:8080`.

## Modalità collaudo nascosta

- Toccare sette volte rapidamente il titolo `58 NERAZZURRI` nella barra superiore.
- In alternativa aggiungere `?debug=58` all'indirizzo.

Il pannello permette di aprire una singola sfida, completarle tutte, aprire direttamente la sala dei regali o azzerare i dati salvati.

## Pubblicazione

Il progetto è un sito statico pronto per GitHub Pages. Pubblicare la root del branch principale.

Le domande storiche del quiz sono basate su fonti ufficiali di FC Internazionale Milano. Il progetto non include stemmi, fotografie, registrazioni o testi musicali protetti.
